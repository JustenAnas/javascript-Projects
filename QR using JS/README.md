# 📱 QR Code Generator

A simple **QR Code Generator** built using **HTML, CSS, JavaScript**, and a public **QR Code API**.  
This project lets you quickly generate QR codes from any text or URL.

---

## 🚀 Features
- Generate QR codes instantly from text or links
- Uses a free QR Code API
- Clean and responsive UI
- Built with **vanilla JS** (no frameworks)

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  
- **QR Code API**
