<h1 align="center">🦖 Dino Game</h1>

<p align="center">
  <b>A fast-paced, retro-style browser game inspired by the Chrome Dino.</b><br>
  <i>Built with pure HTML, CSS, and JavaScript — no frameworks, no limits.</i>
</p>

---

## 🎮 Gameplay
- Press **Spacebar** or **Arrow Up** to jump.
- Dodge **cacti** 🌵 and **birds** 🐦.
- The game gets faster the longer you survive.
- One hit = Game Over. Your score is your bragging right.
