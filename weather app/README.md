#   Weather App

A simple **Weather App** built using **HTML, CSS, JavaScript**, and a public **Weather App API**.  
This project lets you quickly get weather information and also you can know about your  citys weather .

---

## 🚀 Features
- Generate  weather and know about it instantly
- Uses a free   Weather App
- Clean and responsive UI
- Built with **vanilla JS** (no frameworks)

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  
- **Weather App API**
