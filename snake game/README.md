** 🐍 Snake Game **

A simple Snake Game built using HTML, CSS, and JavaScript.
This project brings back the classic arcade experience — eat the food, grow longer, and avoid crashing into yourself or the walls!

🚀 Features

Smooth and responsive gameplay

Classic snake movement mechanics

Dynamic food generation

Real-time score tracking

Restart and replay functionality

Built with vanilla JavaScript (no frameworks)

🛠️ Tech Stack

HTML5

CSS3

JavaScript (ES6)

🚀 Live Demo

🔗 https://snakegamebyanas.netlify.app/

⚙️ How to Run Locally

Clone the repository:

git clone https://github.com/JustenAnas/snake-game.git


Open the project folder:

cd snake-game


Run the game:
Just open index.html in your browser and start playing!

🎮 How to Play
Key	Action
⬆️	Move Up
⬇️	Move Down
⬅️	Move Left
➡️	Move Right

Eat the red squares (food) to grow your snake 🍎

Don’t hit the walls or your own tail 💀

Survive as long as possible to get a high score 🏆
