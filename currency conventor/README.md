# 📱 QR Code Generator

A simple **Currency Convertor** built using **HTML, CSS, JavaScript**, and a public **Currency Convertor API**.  
This project lets you quickly get value of your currency from all around the world.

---

## 🚀 Features
- Generate  currenvcy price  instantly from any currency like USD or INR
- Uses a free  Currency Convertor
- Clean and responsive UI
- Built with **vanilla JS** (no frameworks)

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  
- **CCurrency convertor API**
