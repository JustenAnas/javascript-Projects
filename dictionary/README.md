# 📖 Dictionary App

A simple **Dictionary App** built using **HTML, CSS, JavaScript**, and a free **Dictionary API**.  
Search for any word and instantly get its meaning, pronunciation, and examples.

---

## 🚀 Features
- Look up definitions of any word
- Get phonetics, examples, and part of speech
- Uses a free Dictionary API
- Clean and responsive UI
- Built with **vanilla JS** (no frameworks)

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  
- **Dictionary API**
